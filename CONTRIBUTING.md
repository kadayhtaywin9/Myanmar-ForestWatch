# Contributing to Myanmar ForestWatch

1. Fork this repository and create your feature branch (`git checkout -b feat/my-update`).
2. Run `npm install` and `npm run dev` to test locally.
3. Keep burn evidence curated to **2 best burnt evidences per Reserved Forest** inside the 10 Reserved Forests (`public/data/reserved-forests.geojson`).
4. Ensure `npm run build` succeeds before submitting a Pull Request.

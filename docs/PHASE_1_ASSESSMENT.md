## XGBoost experiment design

Existing target: one or more qualifying recorded VIIRS S-NPP detections per original 5 km cell-month. The six existing predictors are latitude, longitude, month sine/cosine, smoothed cell-season frequency and cell frequency. The first year supplies history. Retain the earlier-year-only feature rule. Keep harmonization coefficients, post-event optical evidence, target-month observations and future weather out of the model. See backend/train.py:13-30 and docs/MODEL_CARD.md:5.

Archived 2024-2025 temporal test results on 14,136 cell-months:

|---|---:|---:|---:|---:|---:|
| Seasonal baseline | .0569 | .8126 | .7106 | .8125 | .7581 |
| Logistic regression | .0898 | .8066 | .7325 | .7715 | .7515 |
| Random forest | .0851 | .8387 | .6929 | .8289 | .7548 |
| XGBoost | Pending | Pending | Pending | Pending | Pending |

These values come from public/data/model-report.json:1. The field named pr_auc is computed with average_precision_score at backend/train.py:34. The baseline won on validation Brier (.06135), while the RF had the highest archived test average precision. The RF eastern holdout F1 is .6643, subject to the threshold issue above. Calibration curves are diagnostics. The outlook repeats seasonal ranks over 36 or 48 months with explicit scenario odds multipliers.

1. Recover and verify the 22 raw archives. Freeze dataset fingerprint, AOI/grid hashes, six feature names/types/order, target, platform and fold membership. Preserve the original model.joblib and public outputs by hash.
2. Add an opt-in training-only dependency and experiment entry point. Reuse backend/train.py features, training_features and metrics. A missing XGBoost package must leave the normal API, baseline, logistic and RF paths usable.
3. Use expanding year folds within 2015-2021 for a bounded seeded search over tree depth, learning rate, min_child_weight, regularization and subsampling. Use CPU hist and a fixed worker budget. Generate fold features from preceding training years. Reserve a later internal block for early stopping with eval_set, record best_iteration and cap the final number of trees. Keep trial scoring separate from its stopping data.
4. Use out-of-fold development predictions for any calibration fit. Compare raw and calibrated Brier, reliability-bin counts and average precision. Retain 2022-2023 for validation/threshold selection, then evaluate the frozen specification on 2024-2025. Its published results are already visible, so disclose this when making later performance claims. For spatial evaluation keep entire held blocks out of all learning steps and report regional and seasonal denominators. Add paired uncertainty estimates that respect years and spatial blocks.
5. Save an independent candidate JSON/UBJ plus configuration, source/data hashes, feature schema, library versions, seeds, fold IDs, calibration parameters, threshold, predictions and metrics. Use a separate experiment report. backend/train.py:54 currently selects a winner automatically and :101 overwrites the production bundle; the candidate run must bypass publication. Update the quality display and model card only with measured results.
6. Test missing dependency, wrong platform, incomplete year, future-label and held-cell perturbation, model round-trip, prediction shape/range and all four candidates on identical partitions. Verify incumbent model, public reports, seasonal risk and harmonization checksums before/after.
